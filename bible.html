📖 Bible API Setup

To read the Bible here (NIV, KJV, Amplified, The Message, and more), you need a free API key from API.Bible — takes about 60 seconds.

  1. Go to scripture.api.bible and click Sign Up Free
  2. Create an account and log in
  3. Go to My Apps → create a new app (name it anything)
  4. Copy the API Key shown and paste it below
scripture.api.bible ↗

Your key is saved in this browser only (localStorage) and never sent anywhere except directly to API.Bible.
