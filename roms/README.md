# Free Game Shelf — hosted homebrew ROMs

Every game in this folder is a modern homebrew title released under an open
license that explicitly allows redistribution. No commercial ROMs, ever.

| File | Game | Console | Author | License | Source |
|------|------|---------|--------|---------|--------|
| nova.nes | Nova the Squirrel | NES | NovaSquirrel | GPLv3 | https://github.com/NovaSquirrel/NovaTheSquirrel |
| libbet.gb | Libbet and the Magic Floor | Game Boy | Damian Yerrick (Pino) | zlib | https://github.com/pinobatch/libbet |
| ucity.gbc | µCity | Game Boy Color | AntonioND (Antonio Niño Díaz) | GPLv3 | https://github.com/AntonioND/ucity |
| dragons-castle.bin | Dragon's Castle | Sega Genesis | Sik (Javier Degirolmo) | zlib | https://github.com/sikthehedgehog/dragon |
| miniplanets.bin | Miniplanets (REMIX) | Sega Genesis | Sik (Javier Degirolmo) | zlib | https://github.com/sikthehedgehog/miniplanets |

Per the GPL, source for the GPLv3 titles is available at the linked
repositories. License texts are preserved in each upstream repo.
